# FireSafety — Campus Fire Alarm Monitoring (planning stage)

A supplementary, monitoring-only graphical management system for fire alarm panels across an academic campus, inspired by Siemens Desigo CC. Designed to run on a VPS with an on-campus edge gateway.

**Status:** specification only — no code yet.

- [Research & MVP plan (Hebrew)](docs/01-desigo-research-and-mvp-plan.md)

> This system is **not** a listed fire alarm control or annunciation device and must never replace the certified fire alarm panel, its annunciators, or the monitoring center.
