## מטרה

מאירוע לוחצים "הצגה במפה" ורואים את הגלאי מסומן על תוכנית הקומה. לכל מפה יש **חלופה טקסטואלית מלאה** (נגישות).

## היקף

1. **קומות למבנה:** שם, מפלס וסדר. ניהול על ידי FireAdmin.
2. **העלאת תוכנית קומה (מאובטחת):**
   - סוגים מותרים: PNG, JPEG ו-WebP בלבד, עד 10MB.
   - **אימות לפי חתימת הקובץ (Magic bytes)**, לא לפי סיומת או Content-Type.
   - **SVG ו-PDF לא נתמכים בשלב זה:** SVG כי הוא עלול להכיל סקריפט, ו-PDF כי פענוח שלו הוא משטח תקיפה. המלצה: לייצא את התוכנית ל-PNG.
   - **הסגר וסריקה:** הקובץ נשמר בסטטוס `pending`, נסרק ב-ClamAV (clamd, INSTREAM), ומוגש רק כשהוא `clean`. קובץ נגוע נמחק, ונרשם אירוע אבטחה ב-Audit.
   - **אחסון:** בטבלת DB נפרדת (`stored_file`), עם שם פנימי UUID, מחוץ ל-public. נכלל בגיבוי ה-DB.
   - **הגשה:** רק דרך API עם בדיקת הרשאה (scope של מבנה), עם `nosniff`, `CSP: sandbox`, `Cache-Control: private` ו-`Content-Disposition: inline` עם שם קבוע.
   - **בייצור סריקה היא חובה** (`UPLOAD_SCANNER=clamav`). `none` מותר רק בפיתוח ובבדיקות.
3. **שיבוץ נקודות:** `point.floor_id`, `x`, `y` כקואורדינטות יחסיות (0–1), לא תלויות ברזולוציית התמונה.
   - שיבוץ בלחיצה על המפה.
   - **חלופה למקלדת:** בחירת נקודה והזנת X/Y באחוזים, וחיצים להזזה.
4. **תצוגת קומה** (לכל משתמש, לפי scope):
   - מפה עם סמנים לפי קטגוריה (צורה, צבע וטקסט), עדכון חי דרך WebSocket.
   - טבלת נקודות הקומה ומצבן, כחלופה טקסטואלית.
   - `?point=<id>` מדגיש נקודה, וזה היעד של הקישור "הצגה במפה" מאירוע.
5. **ייבוא נקודות מ-CSV:**
   - עמודות: `device_instance, object_type, object_instance, building_code, floor_level, label, location, x, y`.
   - מפריד `,` או `;` (זיהוי אוטומטי). תומך בכותרות בעברית ובאנגלית.
   - Dry-run מציג תצוגה מקדימה ושגיאות לכל שורה. החלה בטרנזקציה אחת.
   - מעדכן **רק נקודות שה-Collector כבר דיווח**. שורות שלא נמצאה להן נקודה מדווחות.

## אבטחה

| סיכון | בקרה |
|---|---|
| העלאת נוזקה / Polyglot | Allowlist, magic bytes, ClamAV, הסגר, הגשה כ-image בלבד עם nosniff ו-CSP sandbox |
| XSS דרך SVG | SVG לא מותר |
| DoS בהעלאה | bodyLimit 10MB, rate limit, FireAdmin בלבד |
| IDOR לקבצים ולקומות | כל גישה עוברת דרך building scope (404 מחוץ ל-scope) |
| CSV injection / Parsing | פרסר ייעודי עם מגבלת גודל ושורות, ולידציה של כל תא. אין ייצוא חזרה לגיליון בשלב זה |

## API

| Method | Path | הרשאה |
|---|---|---|
| GET | `/api/buildings/:id/floors` | scope |
| GET | `/api/floors/:id` (כולל נקודות ומצב) | scope |
| GET | `/api/files/:id` | scope של המבנה, ורק קבצים `clean` |
| POST/PATCH/DELETE | `/api/admin/buildings/:id/floors`, `/api/admin/floors/:id` | FireAdmin |
| PUT | `/api/admin/floors/:id/plan` (גוף בינארי) | FireAdmin |
| PATCH | `/api/admin/points/:id` (+ floorId, x, y) | FireAdmin |
| POST | `/api/admin/points/import?dryRun=1` (text/csv) | FireAdmin |
